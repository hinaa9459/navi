# ミチシルベ（iPhone用 かんたんカーナビ）

Safariで動くWebアプリです。Macは不要で、Windowsだけで設置できます。

## 入っているファイル

| ファイル | 役割 |
|---|---|
| index.html | 画面（地図・検索・案内表示・音声） |
| navcore.js | ナビの頭脳（現在地のルート当てはめ、案内文、リルート判定、到着予定、渋滞の判定） |
| routing.js | ルート計算の窓口（2つの無料サーバーを順に試す、有料道路・渋滞区間の回避、交差点名の取り出し） |
| mapstyle.js | 地図の見た目（道路の色分け、建物を薄く、道路名・施設名・信号機名、昼夜の配色） |
| manifest.webmanifest, icon-*.png | ホーム画面に追加したときの名前とアイコン |

## iPhoneで使えるようにする（GitHub Pages・無料）

位置情報は **https のサイト** でしか使えないため、ネット上に置きます。

1. https://github.com でアカウントを作る（無料）
2. 右上「＋」→「New repository」。名前を `navi` などにして **Public** で作成
3. 「uploading an existing file」をクリックし、このフォルダの中身（index.html など9個のファイル）をドラッグして「Commit changes」
4. リポジトリの「Settings」→ 左の「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」
5. 1〜2分後、`https://（ユーザー名）.github.io/navi/` で開けるようになります

## iPhoneでの初回設定

1. 上のURLを **Safari** で開く
2. 共有ボタン（□↑）→「ホーム画面に追加」
3. ホーム画面の「ミチシルベ」を開き「はじめる」→ 位置情報を「許可」
4. 念のため「設定」→「画面表示と明るさ」→「自動ロック」を「なし」に（案内中に画面が消えるとGPSが止まるため）

## 使い方

- 上の「目的地を検索」で施設名・住所を検索（地図の長押しでも目的地にできます）
- ルート確認画面で **有料道路を「使う／使わない」** を切り替えられます（設定画面でも変更可・次回も覚えています）
- 「案内開始」で音声案内スタート。終了ボタンは誤操作防止のため2回タップ
- **「模擬走行」** を押すと、実際に走らなくてもルート上を仮想的に走って案内を確認できます（ボタンで 5/20/40/60/100 km/h 切替）
- ルートを外れると自動で再検索します

## 地図と案内画面

- **地図**：OpenStreetMapのデータを、カーナビ向けの配色で描いています。建物は薄く、道路は種類で色分けしています（高速＝緑、国道など＝オレンジ、県道など＝黄、その他＝白）。道路名・施設名も表示します。夜は暗い配色になります
- **信号機（交差点）名**：地図を拡大すると、横型信号のアイコンと交差点名を表示します。ルート上で曲がる交差点名は、案内表示（青い交差点名標識）と音声（「300メートル先、甲府警察署前を左折です」）にも入ります
- **案内表示**：曲がり角まで300mを切ると、案内板の下に残り距離のバーが出ます。すぐ先にもう一つ曲がり角があるときは「その先」も表示します。走行中の道路名は画面下に出ます
- **自動ズーム**：速度に合わせて表示範囲が変わり、一般道で曲がる交差点の手前では拡大します
- **現在地の動き**：GPSは1秒ごとの更新ですが、その間をルートに沿って補間し、滑らかに動かします。止まっているときはGPSの小さな揺れを無視し、向きも変えません

信号機名はOpenStreetMapに登録されている交差点名を、表示中の範囲ごとに取得しています。登録のない交差点は表示されません。また、取得に数秒かかることがあります。

## ルート計算のしくみ

まず無料サーバー「Valhalla」に問い合わせ、つながらない・混雑しているときは予備の「OSRM」に自動で切り替えます。どちらを使ったかはルート確認画面の下に表示されます。予備のOSRMは有料道路の回避に対応していないため、その場合は画面に注意が出ます。

## 渋滞への対応

| 機能 | 内容 |
|---|---|
| 到着予定の補正 | 案内中、実際の走行ペース（直近10分）と予定を比べ、遅れていれば到着予定に上乗せします。「到着予定 混雑+6分」のように表示されます |
| この先の渋滞を避ける | 約8km/h未満が2分半続くと赤いボタンが出ます。押すと、この先約1.5kmの区間を避けたルートを探し直します（停車中に操作してください）。信号待ち程度では出ません |
| 出発前の確認 | ルート確認画面の「いまの渋滞情報（JARTIC）」から、日本道路交通情報センターの渋滞情報を見られます |

### 渋滞情報を使ったルート計算をしていない理由

渋滞データ入りのルート計算サービスを調べましたが、このアプリでは規約上使えるものがありませんでした（2026年10月時点）。

- Google Routes API：Google以外の地図との併用、音声読み上げでの利用が規約で禁止
- Mapbox：車で使うアプリは、開発段階から別途の有料商用ライセンスが必要
- HERE：日本の地図データは個別の契約が必要
- TomTom：日本はルート検索の対象外

そのため、ルートの所要時間そのものには渋滞が含まれません。

## 知っておいてほしい制限

- 使っている無料サービス（地図＝OpenFreeMap、信号機名＝Overpass API、検索＝国土地理院・OpenStreetMap、ルート＝Valhalla・OSRM）は登録不要ですが、品質保証はありません。地図が読めないときは国土地理院の淡色地図に自動で切り替わります。ルートサーバーが両方とも止まるとルートを計算できません
- 「有料道路を使わない」は、ほかに道がない場合は一部で有料道路を通ることがあります（そのときは画面に注意が出ます）
- 圏外では地図もルートも取得できません
- 案内は目安です。実際の標識・交通規制を優先してください。操作は停車中に
